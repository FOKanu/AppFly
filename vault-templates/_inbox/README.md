# Inbox

Drop Obsidian Web Clipper notes here (Markdown or HTML). `jobhunt scout` turns them into `Jobs/` notes.

Include a title heading, the company name, and the listing URL.

You may clip a **single listing you already opened** on LinkedIn / Indeed / Stepstone. Scout only reads this file. It will not fetch that URL, and Apify must never be pointed at those hosts (account ban risk). Do not clip search-result pages.
