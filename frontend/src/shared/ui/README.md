# Shared UI

Tokens, buttons, and edge-state chrome (`Banner`, `EmptyState`, `OfflineBanner`) live in `src/shared/ui/`. `useBreakpoint` is in `src/shared/`. Feature screens belong in `src/features/<name>/`. Point `VITE_API_BASE_URL` at the local API; never put Gemini or Apify keys in frontend env files.
