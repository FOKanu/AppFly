# Brand

`appfly-mark.png` — the AppFly wing mark, exported from the FigJam board's
"App Logo" section with its light background removed. Used by `Sidebar` at 24px
and, via `public/appfly-mark.png`, as the favicon.

`appfly-logo.png` — the full lockup (mark + wordmark + tagline), kept for
places that need the horizontal logo. Not referenced yet.

Both are raster because the board holds the logo as an image, not vectors.
Do not hotlink the Figma CDN; re-export here if the board changes.
