# Jobhunt Copilot UI

Vite + React + TypeScript scaffold. Dark instrument-panel tokens live in `src/shared/ui/tokens.ts`. Feature folders under `src/features/` are README-only until sibling agents land screens.

```bash
cp .env.example .env
npm install
npm run dev
npm run build
```

`VITE_API_BASE_URL` defaults to `http://127.0.0.1:8787`. No API keys belong in frontend env files.
