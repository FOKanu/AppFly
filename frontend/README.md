# Frontend (scaffold)

Vite + React + TypeScript shell. No product screens yet.

- Routes: `src/routes.ts`
- Providers/router: `src/app/App.tsx`
- Layout placeholder: `src/app/layout/AppShell.tsx`
- Screens: `src/features/<name>/` (see each README)

```bash
cd frontend
npm install
npm run dev
npm run build
```

API base: `VITE_API_BASE_URL` in `.env.example` (copy to `.env` later). No API keys in this package.
